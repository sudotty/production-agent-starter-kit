# Authorized lab example

This directory is intentionally sample-free.

A future reproducible example should:

1. build a small open-source Android application locally,
2. record the build hash,
3. create an authorized test variant,
4. initialize a Traceforge mission,
5. capture baseline static observations,
6. run controlled before/after UI experiments,
7. calculate semantic Recovery Score,
8. export evidence and a report.

Do not commit proprietary APKs, live credentials, captured customer data, or
third-party session tokens.
