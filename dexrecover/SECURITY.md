# Security and Responsible Use

DexRecover is intended for authorized Android reverse-engineering and defensive research.

Use it only with:

- applications you own,
- applications you have explicit permission to test,
- redistributable research samples,
- CTF/lab targets,
- lawful defensive malware-analysis samples.

DexRecover does not need credentials or live customer data. Do not commit private APKs, recovered proprietary source, session tokens, or captured customer information to this repository.

The project focuses on DEX recovery evidence and validation. It does not aim to automate exploitation or unauthorized access.
